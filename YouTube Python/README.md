# YouTube Python

Complete 100-video Python Basics YouTube course.

## Production target
- 100 separate videos: PY-001 through PY-100
- Simple English for beginners
- Step-by-step teaching
- VS Code-style coding visuals
- Consistent AI narration
- Captions
- Challenge + answer + recap
- Progress at the end of every lesson
- PY-100: 100/100 — 100% COMPLETE + "This is not the end of your journey. This is only the beginning."
- Normal target: 2–5 minutes
- Absolute maximum: 10 minutes
- 16:9 YouTube landscape
- No camera and no watermark

## Batch file
Use:
YouTube Python/input/scripts/input-scripts.json

The JSON contains all 100 lessons in deterministic order.

## Important
This repository stores the course production manifest. A video generator must render each lesson into its own MP4. The GitHub manifest itself is not an MP4 generator.
