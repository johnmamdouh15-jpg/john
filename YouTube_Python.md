# YouTube Python — 100-Video Course

## Production rules
- 100 beginner-to-advanced Python lessons, ordered as one continuous course.
- Target length: 5 minutes or less per video.
- Language: simple, clear English for complete beginners.
- Visual style: realistic VS Code screen; show Python code being typed, explained, and run step by step.
- Teaching flow for every video: Hook → Objective → Explain one concept → Type the code → Run it → Show the result → Tiny challenge → Answer → Recap → Progress counter → Encouragement → Next lesson.
- Keep the same visual identity and teaching voice across the full course.
- End every video with an encouraging line and a progress counter such as `Course progress: 07/100 — 7% complete.`
- Do not claim that the course makes money or guarantees views; the counter is a motivation device only.

## Progress-counter mapping
Video N always displays `Course progress: N/100 — N% complete.` Use the exact lesson number so viewers can see steady progress through the course.

## Standard ending
After the recap, show the progress counter for 2–3 seconds, then use a short encouraging line such as: `Great job. You are one step closer to mastering Python. See you in the next lesson!`

## Video-generation brief
Create each lesson as a finished educational YouTube video, not as a script-only document. The final visual should feel like a real beginner coding lesson: VS Code on screen, readable Python code typed progressively, cursor movement, execution/output, simple callouts, and clear English narration. Keep explanations focused on the lesson topic and avoid unnecessary advanced material.

## Important implementation note
This repository file is the master course/production manifest. The actual MP4 video files must be generated by a video-generation/rendering pipeline and stored as video assets; GitHub's text-file API is not a video renderer or binary video host.
